# Caro 3×3 sử dụng thuật toán Minimax

Bài tập lớn học phần Trí tuệ nhân tạo — Đại học Công nghiệp Hà Nội.

## Chức năng
- Đăng ký, đăng nhập.
- Chơi với máy bằng thuật toán Minimax.
- Chơi người với người trên cùng thiết bị.
- Chọn quân X/O, đổi tiếng Việt/tiếng Anh.
- Lưu lịch sử ván chơi.

## Chạy chương trình
Cài Python 3 có Tkinter, tải mã nguồn và mở Terminal trong thư mục dự án:

```bash
python app.py
```
